# vhtml-ui 视觉契约

## 北极星

清晰、精密、可组合的开发工具。组件首先服务状态识别与操作效率，装饰不得抢过真实内容。

## 骨架与密度

- 组件库的主角是真实组件及其状态；文档主动作是试用组件、查看代码与查 API。
- 默认控件采用 36px 中等尺寸，30px 小尺寸；同组控件基线、边框与圆角一致。
- 组内间距 4–12px，组间间距 20–48px。留白用于分组，不用重复描边制造层级。
- 文档页采用导航、内容工作台两级结构；首页首屏使用真实组件工作台，不使用浮动拼贴。

## 字体与色彩

- 正文使用系统字体；代码使用 ui-monospace / Menlo / Monaco。暗色主题不切换正文字体。
- 正文、辅助、禁用分别使用 `--v-text-color` / `secondary` / `disabled`。
- 信号蓝只用于主动作、选中、焦点与信息状态。普通导航和图标保持中性色。
- 浅色画布为中性灰，组件表面为白色；暗色使用同层级中性色，不使用蓝黑渐变。

## 控件语法

- 主圆角 8px，小标签 5px，工作台与对话框 12px；胶囊只用于明确的圆形控件。
- 实色按钮表示主动作，描边按钮表示次动作，ghost 用于低密度工具区。
- hover 只改变表面或边框；active 使用 1px 按压反馈；focus 使用可见焦点环；disabled 同时降低对比并禁止操作。
- 弹层阴影只用于表达浮起层级，普通卡片不使用大阴影。

## 放弃项

不使用紫蓝绿渐变标题、背景光斑、无意义浮动动画、每张卡片独立彩色图标或暗色等宽正文。

## 验收

至少检查首页、按钮、输入页的明暗主题和中英文；确认文字不重叠、语言组件有确定尺寸、窄屏可导航，且组件公开 API 与交互不变。
